# ReviewLoop

**Product name:** ReviewLoop.

ReviewLoop is a local-first dashboard for AI review pipelines: generate a brief, run parallel reviewers, consolidate findings, and hand a focused task to Cursor.

## Positioning

- Local-first and privacy-friendly.
- Demo mode for immediate evaluation.
- Bring your own API keys.
- Clear upgrade path for hosted teams.

## Landing Page Outline

1. Hero: "Turn AI code review into an explicit workflow."
2. 30-second demo GIF or short video.
3. Three cards: Orchestrate, Review, Handoff.
4. Quickstart: `docker compose up --build`.
5. GitHub CTA and hosted waitlist CTA.
